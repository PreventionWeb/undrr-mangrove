## Install Mangrove

Mangrove supports plain HTML and CSS, Sass, and React. Start with the package, then follow the <LinkTo kind="getting-started-getting-started-guide" story="docs">getting started guide</LinkTo> for the setup that matches your project.

<Source language="bash" code="npm install @undrr/undrr-mangrove" />

Each UNDRR property themes components independently. The shared layer is the semantic content structure—the parts that let syndicated content render correctly and accessibility fixes propagate to every site at once. Mangrove is used on [undrr.org](https://www.undrr.org), [PreventionWeb](https://www.preventionweb.net), [MCR2030](https://mcr2030.undrr.org), and partner sites.

### Choose an integration path

- <LinkTo kind="getting-started-integration-vanilla-html-and-css" story="docs">
    Vanilla HTML and CSS
  </LinkTo>
  — add compiled CSS and use semantic HTML structures without a build step
- <LinkTo kind="getting-started-integration-sass-integration" story="docs">
    Sass
  </LinkTo>
  — customize themes, variables and the build process
- <LinkTo kind="getting-started-integration-react-integration" story="docs">
    React
  </LinkTo>
  — use components with props-based customization
- <LinkTo kind="getting-started-integration-hydration-guide" story="docs">
    Hydration
  </LinkTo>
  — attach React behavior to server-rendered HTML from Drupal or Astro
- <LinkTo kind="getting-started-ai-and-mcp-integration" story="docs">
    AI and MCP
  </LinkTo>
  — give coding agents structured Mangrove component metadata
